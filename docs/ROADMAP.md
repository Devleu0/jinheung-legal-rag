## 평가 방법

현재 `scripts/evaluate.py`는 데모 검색 smoke test일 뿐 법률 정확도 측정이 아닙니다. 실제 수집 데이터에 대해 3분야 각 20개 질문, 무관 질문 15개, 후속 질문 15개를 따로 구성합니다. 튜닝용/최종 평가용을 분리하고 법률 검수자에게 정답 조항과 부정확한 적용을 표시하도록 요청합니다.

측정: Recall@3, MRR, 인용 ID 유효율, 문자열 일치율, 근거 부족 거절율, 잘못된 단정 비율, 응답 p50/p95, 질문당 토큰/비용. BM25 단독·lexical RRF·embedding RRF를 비교하세요. 목표(미달성): Recall@3 ≥ 0.8, 인용 형식 유효율 1.0, 전문가 평가에서 위험한 단정 0건. 실제 수치 없이 달성했다고 발표하지 않습니다.

발표는 무료 시연 → 문서/각주 확인 → 후속 질문 → 세션 격리/삭제 → 근거 없음 → API 연결 준비사항 → 한계 순서로 진행합니다.
